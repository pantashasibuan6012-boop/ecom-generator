# E-Commerce Platform Generator

Generate customized online stores with inventory, payments, and AI recommendations.

## Features
- Multi-payment gateway (Stripe, Midtrans, Xendit)
- Inventory management with auto-reorder
- AI product recommendations
- Multi-currency support
- SEO optimization

## Installation
```
pip install -r requirements.txt
```

## Usage
```
python main.py create 'Fashion store with 50 products'
python main.py deploy store-name --platform vercel
```
